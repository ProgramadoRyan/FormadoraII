Avaliação Formadora II

O aplicativo foi criado como parte da Avaliação Formadora II, atividade desenvolvida na disciplina de Desenvolvimento de Aplicações Móveis. A proposta envolve aplicar, na prática, os conceitos aprendidos em aula sobre desenvolvimento mobile.

Recursos presentes no projeto:

  • Página que realiza o consumo de uma API externa.
  • A proxima tela, apresenta as minhas informações.
  • Navegação entre páginas implementada de forma dinâmica.
